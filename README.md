# ontosepsis-kg-reproduction

Reproduction of *OntoSepsisKG: Omics-based Knowledge Graph for Sepsis*
(Forero Camacho, Seghouani, Tournois, Zehraoui — GOLE workshop, EGC 2025),
on the GSE54514 transcriptomic dataset.

Builds an OWL knowledge graph linking patients, samples, genes, proteins,
GO terms and pathways from public gene expression data.

Work in progress.
